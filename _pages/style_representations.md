I provide several resources that you might find useful if you already are interested in style (representations). And resources to convince you that you should be more interested in style representations.

**Survey Paper:** [A Plea for More Style Representations (Preprint)](https://annawegmann.github.io/pdf/Style_Survey_preprint.pdf) — Our survey paper on style representations, covering definitions, models, datasets, and open challenges. I'll present it at EMNNLP 2026 Hall H	Session 10	Poster Session F	2026-10-27	09:00	10:30.

**Companion Website:** [StyleSurvey](https://annawegmann.github.io/StyleSurvey/) — An interactive companion site with curated resources organized into papers, definitions, models/tools, and datasets related to style representations. This is far from exhaustive, help with pull requests or e-mails!

**Code Repository:** [GitHub](https://github.com/AnnaWegmann/StyleSurvey) — The repository behind the companion website, containing code, quickstart guides, and all collected resources.

**Style Benchmark**: I'm also presenting [https://arxiv.org/abs/2606.31741](STEB: Style Text Embedding Benchmark) at EMNLP 2026. G13-14	Session 5	Resources and Evaluation 3	2026-10-26	09:00.
